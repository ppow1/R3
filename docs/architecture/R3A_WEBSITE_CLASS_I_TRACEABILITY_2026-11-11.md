# Class I Riverview Website requirement traceability — 2026-11-11

## Source authority and status rules

This recovery uses the complete Class I scope and standing Website backlog in [Issue #51](https://github.com/ppow1/R3/issues/51), including the later conversation UX specification ([comment 6769718391](https://github.com/ppow1/R3/issues/51#issuecomment-6769718391)) and continuation ([comment 6770760857](https://github.com/ppow1/R3/issues/51#issuecomment-6770760857)); [AP3 Steward Access](R3A_AP3_STEWARD_ACCESS.md), the [Website session contract](R3A_STEWARD_WEBSITE_SESSION_CONTRACT.md), the [Website API contract](R3A_STEWARD_WORKSPACE_WEB_API_V1.md), the [AP0–AP6 roadmap](R3A_MASTER_ROADMAP_AP0_AP6.md), and both [R3A and inherited punch lists](R3A_PUNCH_LIST_AND_PARKING_LOT.md, ../../docs/PUNCH_LIST.md). The [2026-11-11 evidence matrix](R3A_WEBSITE_ACCEPTANCE_MATRIX_2026-11-11.md) remains the concise current-state summary.

Status labels apply to a named source revision and evidence type:

- **Implemented + tested:** permanent tests verify the Website behavior; authenticated operational acceptance may still be open.
- **Partial:** a safe, evidenced subset exists, while requirement parts remain absent or live acceptance is unverified.
- **Missing:** no Website implementation or approved backing interface exists.
- **Blocked by external dependency:** the Website adapter/UI is ready or intentionally gated; a named authority, service contract, provider, deployment, or real Steward action is required.
- **Deferred by approved phase:** roadmap ownership is later (for example, AP5 spatial presentation) and does not gate desktop/mobile function.

Status distinction is mandatory: a route, panel, mock fixture, passing unit test, source archive, or healthy process is not by itself live acceptance. Exact current Website source HEAD and the package-source SHA are reported on #61/#51. The packaged Website remains a source candidate until exact artifact audit, Coordinator integration, controlled deployment, and the relevant authenticated browser/API acceptance pass.
