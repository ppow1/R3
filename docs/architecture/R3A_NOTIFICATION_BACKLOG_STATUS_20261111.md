## Current audit rework and release gate

Auditor FAIL #48 comments [6803428149](https://github.com/ppow1/R3/issues/48#issuecomment-6803428149) and [6804672208](https://github.com/ppow1/R3/issues/48#issuecomment-6804672208) identified raw-byte hash mismatch risks in the read manifest's `store.py` supporting artifact and `capability.py` primary artifact on Windows `core.autocrlf=true`. Both paths are now pinned to LF in `.gitattributes`; a permanent disposable Git clone regression uses `core.autocrlf=true`, checks both exact hashes, and registers the extracted manifest with the standard loader. The deterministic package builder and extracted-package registry install test remain. This candidate still needs commit/push and exact-SHA Auditor re-review.

The AP3 write constraint remains a shared contract dependency, not a notification-side exception. The package deliberately declares only `notification.delivery.read`. No wildcard, hardcoded human, service identity substitution, or Website-provided principal authority is allowed. No managed bootstrap, grant, provider activation, Website deployment, live inbox, acknowledgment, or resolution was changed or verified in this workstream.
